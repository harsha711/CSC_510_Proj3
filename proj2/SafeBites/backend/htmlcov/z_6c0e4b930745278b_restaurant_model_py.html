1""" 

2Defines Pydantic models for handling restaurant and menu-related data 

3in the SafeBites backend. 

4 

5Models: 

6 

7- RestaurantBase: Basic restaurant information. 

8- RestaurantCreate: Schema for creating a new restaurant. 

9- RestaurantUpdate: Schema for updating an existing restaurant. 

10- RestaurantInDB: Database representation of a restaurant. 

11- PriceFilter: Filter for dish prices. 

12- IngredientFilter: Include/exclude ingredient filters. 

13- AllergenFilter: Exclude allergen filters. 

14- NutritionFilter: Nutritional constraints for dishes. 

15- DishFilterModel: Aggregates all dish filters. 

16- DishValidationResult: Outcome of validating a dish against filters. 

17- MenuQueryResults: Result of a menu search query. 

18- MenuResultResponse: Structured response for menu retrieval. 

19 

20These models are used throughout the backend for validation, data exchange, 

21and API responses. 

22"""
